De en_GB dictionaries komen van Libreoffice vandaan en kun je opnieuw downloaden met:

```
wget -O en_GB.aff https://raw.githubusercontent.com/LibreOffice/dictionaries/master/en/en_GB.aff
wget -O en_GB.dic https://raw.githubusercontent.com/LibreOffice/dictionaries/master/en/en_GB.dic
wget -O nl_NL.aff https://raw.githubusercontent.com/LibreOffice/dictionaries/master/nl_NL/nl_NL.aff
wget -O nl_NL.dic https://raw.githubusercontent.com/LibreOffice/dictionaries/master/nl_NL/nl_NL.dic
```
